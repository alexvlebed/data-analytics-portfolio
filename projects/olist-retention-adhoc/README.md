# Olist Retention Analysis — почему 97% клиентов не возвращаются?

Ad-hoc аналитический запрос от команды роста Olist: понять, какие характеристики **первой покупки** связаны с вероятностью возврата клиента, и предложить гипотезы для улучшения retention.

---

## Контекст

[Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce) — бразильский маркетплейс. По публичным данным, **лишь ~3% клиентов совершают повторную покупку**. Команда роста поставила задачу разобраться, что связано с возвратом, и дать 2–3 действенные гипотезы.

Это **одноразовый ad-hoc запрос**, а не дашборд и не ETL-пайплайн. Цель — исследование и выводы, а не production-решение.

---

## Бизнес-вопрос

> Какие характеристики **первой покупки** клиента коррелируют с вероятностью возврата? Что из этих факторов команда может изменить?

---

## Что ожидается

- **Jupyter-ноутбук** — воспроизводимый анализ с текстовыми рассуждениями между ячейками
- **Презентация на 5 слайдов** — контекст → находки → модель → рекомендации → next steps
- **Витрина `customer_first_order`** — одна строка на клиента, parquet/CSV, для переиспользования

---

## Данные

Датасет: [Brazilian E-Commerce Public Dataset by Olist](https://www.kaggle.com/datasets/olistbr/brazilian-ecommerce)
Объём: ~100k заказов, 9 CSV-таблиц, ~120 МБ.

Используемые таблицы:

| Файл | Содержание |
|---|---|
| `olist_customers_dataset.csv` | Клиенты и их география |
| `olist_orders_dataset.csv` | Заказы, статусы, таймстемпы |
| `olist_order_items_dataset.csv` | Позиции заказов |
| `olist_order_payments_dataset.csv` | Платежи |
| `olist_order_reviews_dataset.csv` | Отзывы и оценки |
| `olist_products_dataset.csv` | Товары |
| `product_category_name_translation.csv` | Перевод категорий |

## 🧪 Гипотезы

| # | Гипотеза | 
|---|---|---|
| **H1** | Высокий первый чек → чаще возвращаются |
| **H2** | Долгая доставка снижает возврат |
| **H3** | Негативный отзыв (`review_score ≤ 2`) снижает retention |
| **H4** | Категория первого заказа влияет на возврат |
| **H5** | Штат клиента влияет на retention |
